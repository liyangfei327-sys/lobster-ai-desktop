# dsh-lobster-ai

DeepSeek Harness minimal plugin bundle for Lobster AI.

## Files
- package.json
- cordis.patch.yml
- index.js

## Install
Use the `harness-plugin` directory from this repository as the plugin source in DeepSeek Harness.

## Current status
This version is intended to let DeepSeek Harness recognize and load the plugin bundle. It does not yet connect the original Electron desktop pet logic.
